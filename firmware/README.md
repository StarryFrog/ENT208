# Firmware Folder

This folder contains the hardware-side firmware code for the FitSense project.

Main features include:

- Bluetooth Low Energy (BLE) communication

- Heart-rate monitoring with MAX30102

- Running detection

- Push-up detection

- Bench press detection

- Motion sensing using the built-in IMU

- Buddy pet reminder animation

- Real-time data transmission to Android devices

The firmware is designed for M5StickS3 using MicroPython / UIFlow.

# firmware 文件夹

此文件夹用于存放 FitSense 项目的硬件端固件代码。

主要功能包括：

- 蓝牙 BLE 通信

- MAX30102 心率监测

- 跑步检测

- 俯卧撑检测

- 卧推检测

- 基于 IMU 的动作感知

- Buddy 宠物提醒动画

- 与安卓设备的实时数据传输

该固件基于 M5StickS3，并使用 MicroPython / UIFlow 开发。
